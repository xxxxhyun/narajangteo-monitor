GitHub 연결

처음 한 번만 하면 이 브라우저가 기억합니다. 설정은 GitHub 저장소의 config.json에 저장되고, 다음 발송부터 바로 적용됩니다.

토큰 만드는 방법 (처음 한 번)
  1. GitHub → 오른쪽 위 프로필 → Settings → 맨 아래 Developer settings
  2. Personal access tokens → Fine-grained tokens → Generate new token
  3. Token name: 나라장터 설정, Expiration: 1년
  4. Repository access: Only select repositories → narajangteo-monitor
  5. Permissions → Repository permissions: Contents: Read and write, Actions: Read and write
  6. Generate token → 표시된 값을 복사해 위 칸에 붙여넣기 (다시 볼 수 없으니 바로 붙여넣으세요)

토큰은 이 브라우저에만 저장되고 GitHub 외에는 전송되지 않습니다. 공용 PC에서는 "기억"을 끄세요.

발송 시간 · 주기

선택한 요일의 선택한 시각마다 그 사이 새로 올라온 건을 보냅니다. 여러 시각을 고르면 하루 여러 번 받습니다.

GitHub 서버 사정으로 실제 도착은 선택 시각 기준 17분~1시간 정도 늦을 수 있습니다. 실패하면 3시간 안에 자동 재시도합니다.
